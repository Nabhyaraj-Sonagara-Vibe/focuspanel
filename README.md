# FocusPanel

A colourful, native **macOS Pomodoro timer with an integrated to-do list**, in a
compact always-on-top floating window. Built in Swift + SwiftUI/AppKit as a Swift
Package (builds, tests, and runs from the command line).

> 🚧 The implementation lands via the `build/focuspanel` pull request. See that PR
> for the full app, tests, and CI.
